# School branding

Put the school's logo in this folder as **`logo.png`** (or `logo.svg`, `logo.jpg`, `logo.webp`).
The app picks it up on the next page load. No restart is needed.

- It appears at the top of every page, on the sign-in page and on printed reports.
- A wide logo works best: the full Learning International Schools logo with its English and Arabic name.
- While no file is here, the app shows a simple mark in the school's colours, with the school's name beside it.

The app icons for phones (`src/athar/web/static/brand/icon-*.png`) are separate files. To use the real logo
there too, replace them with square PNGs of the same sizes (180, 192 and 512 pixels).
